قبل از استفاده:
1) در GitHub وارد Settings ریپو شوید.
2) اگر ریپو Private است، آن را Public کنید؛ وگرنه curl به raw.githubusercontent.com فایل را نمی‌خواند.
3) این فایل‌ها باید در ریشه ریپو باشند: wizwiz.sh، update.sh، dbbackupwizwiz.sh و فایل‌های پروژه.

دستور نصب:
bash <(curl -fsSL https://raw.githubusercontent.com/HajPorya/wizwiz-porya/main/wizwiz.sh)

دستور آپدیت:
bash <(curl -fsSL https://raw.githubusercontent.com/HajPorya/wizwiz-porya/main/update.sh)
